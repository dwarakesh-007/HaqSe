# Contributing to HaqSe

Thanks for helping make law easy for everyone.

## Ways to help

**1. Legal content (no coding needed)**
- Check and improve a file in `legal-content/central/`
- Fill in or verify a state file in `legal-content/states/`
- Add a new state (copy `telangana.json` and fill it in)
- Improve a letter template in `templates/`

Every fact must come from an official source (a government website, the Act itself, or a lawyer). Add the source link in your pull request.

**2. Translations**
- Telugu and Hindi wording for the app's buttons and messages

**3. Code**
- Pick an item from [docs/ROADMAP.md](docs/ROADMAP.md)

## How to contribute

1. Fork the repo, or ask to be added as a collaborator
2. Create a branch: `git checkout -b your-name/what-you-are-doing`
3. Make your change and commit it with your own GitHub account
4. Open a pull request explaining what you changed and why

## Ground rules

- Simple words first. If your grandmother wouldn't understand it, rewrite it.
- Never invent a law, fee, phone number or website.
- Mark anything you're unsure about with `TODO: verify`.
