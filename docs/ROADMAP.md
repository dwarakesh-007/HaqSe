# HaqSe Roadmap

## Version 1 (now)
- [x] Home screen with state and language picker
- [x] Three areas: consumer problems, cyber fraud, RTI
- [x] Chat that asks follow-up questions and explains rights in plain words
- [x] AI answers only from checked legal content
- [x] Document drafting with PDF download
- [x] Voice input (browser speech recognition)
- [x] "Get human help" safety line for serious cases
- [x] Court walkthrough for each area
- [x] Case strength check (strong / medium / weak, with how to fix weak points)
- [ ] Review all legal content with a lawyer or law student
- [ ] Verify Telangana and Andhra Pradesh state details
- [ ] Telugu / Hindi font support in PDFs (add a Noto Sans font to jsPDF)
- [ ] Translate the app's buttons and labels into Telugu and Hindi
- [ ] Deploy on Vercel

## Version 2
- Case tracker with reminders ("7 days passed, time for step 2")
- Evidence checklist per area
- Full voice-first mode, with Bhashini for better Indian-language speech
- User accounts (Supabase) to save cases

## Version 3
- More areas: tenant problems, unpaid salary
- More states
- Connect users to legal aid volunteers for serious cases
